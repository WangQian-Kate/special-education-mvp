# 成员 B 行为目录与状态栏实施报告

## 实施基准

本次以后端仓库内的确认版 `backend/docs/source/行为条目及状态栏.md` 为唯一内容基准。生成器按源文件顺序分配稳定主行为编码 `B001-B100`，并保存源文件 SHA-256，防止静默漂移。

## 已实施内容

- 解析并校验 9 个模块、100 个主行为、88 个子行为、531 个表现/状态选项、28 个前端分组和 3 个分组状态栏选项。
- 建立 368 条课程推荐、196 条环境推荐和 155 条训练目标关系。
- 训练目标关系精确覆盖 11-165，不重不漏。
- 行为卡片改为课程与环境共同筛选；全天汇总只跳过课程限制。
- 详细记录支持多选子行为和表现状态，并校验主行为归属、父子关系与“其它”自定义文本。
- 保留 A/B/C 自由文本、行为功能、辅助方式和辅助结果原有能力。

## 数据库

- 迁移：`backend/sql/migrate-v2.6-behavior-catalog.sql`。
- 数据库版本：`2.6.0`。
- 表数量：27 张。
- 新增 9 张行为目录相关表，关键关联均有外键和查询索引。
- 旧行为记录存在时迁移会主动中止，避免无映射替换旧编码。
- 本地迁移前备份保存在被 Git 忽略的 `backend/backups/`。

## 可重复生成

执行：

```powershell
python backend\scripts\generate_behavior_catalog.py
```

输出：

- `backend/docs/behavior-catalog.json`
- `backend/sql/seed.sql` 中的受控生成区

生成器会硬校验模块数、每模块行为数、主行为连续编码和目标完整性。

## 验证结果

- Maven 数据库集成测试：7 个场景，0 失败。
- 目录完整性：所有主行为均有关联课程、环境和训练目标。
- 父子状态孤儿：0。
- 目标子行为孤儿：0。
- OpenAPI 版本：`0.11.0`。
- 临时本地实例实测目录接口：`CHINESE + CLASSROOM` 返回 16 项和 3 个入班准备状态栏选项；预热后 50 次请求平均 `18.36 ms`，最小 `13.96 ms`，最大 `27.73 ms`。
