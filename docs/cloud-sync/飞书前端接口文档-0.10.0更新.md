# 飞书前端接口文档 0.10.0 手动更新内容

目标文档：[特殊教育课堂助手 V2 前端接口文档](https://nankai.feishu.cn/wiki/XIhbwUYGGildJSkv7sSca0aMn8g)

## 版本

将契约版本由 `0.9.0` 更新为 `0.10.0`。接口数量仍为 24，没有新增或删除接口。

## 新增课程和环境字典说明

在“枚举值”后新增以下说明：

- 课程：`CHINESE` 语文、`MATHEMATICS` 数学、`ENGLISH` 英语、`PHYSICAL_EDUCATION` 体育、`MUSIC` 音乐、`ART` 美术、`SCIENCE` 科学、`MORAL_EDUCATION` 道法、`PHYSICAL_TRAINING` 体能、`INDIVIDUAL_TRAINING` 个训、`BREAK` 课间、`LUNCH` 午餐、`NOON_REST` 午休、`SELF_STUDY` 自习、`OTHER` 其他、`ALL_DAY_SUMMARY` 全天汇总。
- “劳动”“综合”“地方”统一提交 `OTHER`，具体内容写入 `courseOtherDescription`。
- 环境：`CLASSROOM` 普通教室、`RESOURCE_CLASSROOM` 资源教室、`PLAYGROUND` 操场、`CORRIDOR` 楼道、`RESTROOM` 卫生间、`OFF_CAMPUS` 校外、`OTHER` 其他。
- 选择其他环境时，补充内容写入 `environmentOtherDescription`。

`courseCode` 和 `environmentCode` 的 OpenAPI schema 已改为上述固定枚举，前端不得提交列表外的 code。
