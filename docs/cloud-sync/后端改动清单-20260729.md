## 三、训练目标查询修复

### 3.1 修改文件

| 文件 | 改动 |
|------|------|
| `mapper/TrainingPlanMapper.xml` | `countGoalRecords` / `findGoalRecords` 查询增加子行为匹配条件：同时匹配 code、label、NULL 三种情况 |

### 3.2 问题说明

前端记录子行为时存入的是完整中文标签（如"向老师提问简单问题"），训练目标映射表存的是 code（如 `B103_S02`）。原 SQL 只按 code 匹配，导致绝大部分训练目标查不到关联记录。修复后同时按 code 和 label 匹配。
