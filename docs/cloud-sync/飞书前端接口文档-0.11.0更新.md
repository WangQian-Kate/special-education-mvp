## 版本说明

- 契约版本由 `0.10.0` 更新为 `0.11.0`。
- 接口总数仍为 24，没有新增或删除路径。
- `GET /class-records/behavior-options` 从简单 `CodeLabel[]` 升级为标准行为目录 `BehaviorCatalogItem[]`。

## 行为目录接口

`GET /class-records/behavior-options?courseCode=CHINESE&environmentCode=CLASSROOM`

- `courseCode` 必填。
- `environmentCode` 可选；提供后返回课程与环境推荐关系的交集。
- `ALL_DAY_SUMMARY` 不限制课程，但仍按环境筛选。
- 每项返回：`B001-B100` 主行为、九大模块、前端分组及状态栏、推荐课程/环境、训练目标、子行为和表现/状态选项。
- “入班准备”分组的 `statusOptions` 固定返回未完成、辅助、独立；其他未定义状态栏的分组返回空数组。
- `requiresCustomText=true` 表示“其它”状态必须填写自定义文本。

完整结构以 `backend/docs/openapi.yaml` 和 `backend/docs/behavior-catalog.json` 为准。

## 详细记录请求新增字段

```json
{
  "subBehaviorCodes": ["B001_S01"],
  "performanceSelections": [
    {
      "optionCode": "B001_P04",
      "customText": null
    }
  ]
}
```

规则：

- 两个数组均可省略或传空数组，并支持多选。
- 选项必须属于当前行为记录的主行为。
- 有父子行为的表现状态必须同时选择对应子行为。
- `requiresCustomText=true` 的状态必须填写 `customText`，其他状态禁止填写。
- 子行为或表现状态也算“详细记录的一项内容”，保存成功后 `detailSaved=true`。

## 行为编码迁移

旧演示编码不再使用；正式主行为稳定编码为 `B001-B100`，顺序严格对应《行为条目及状态栏》。前端应始终从行为目录接口读取展示文本和选项，不在代码中复制完整字典。
