# 飞书数据字典 v2.8.0 手动更新内容

## 新增表

### wechat_identity（微信身份绑定）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT UNSIGNED PK | |
| user_id | BIGINT UNSIGNED FK→app_user | |
| app_id | VARCHAR(32) NOT NULL | 小程序AppID |
| openid | VARCHAR(128) NOT NULL | 微信openId |
| unionid | VARCHAR(128) | 微信unionId |
| created_at | DATETIME NOT NULL | |
| last_login_at | DATETIME NOT NULL | |

### auth_session（登录会话）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT UNSIGNED PK | |
| user_id | BIGINT UNSIGNED FK→app_user | |
| token_hash | VARCHAR(64) NOT NULL | SHA-256(token) |
| expires_at | DATETIME NOT NULL | 默认7天 |
| revoked_at | DATETIME | NULL=有效 |

### teacher_binding_code（教师绑定码）
| 字段 | 类型 | 说明 |

| id | BIGINT UNSIGNED PK | |

| code_hash | VARCHAR(64) NOT NULL | SHA-256 |
| expires_at | DATETIME NOT NULL | |
| consumed_at | DATETIME | 使用时间 |

### training_goal_change_log（训练目标变更日志）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT UNSIGNED PK | |
| student_goal_id | BIGINT UNSIGNED FK→student_training_goal | |
| standard_number | SMALLINT UNSIGNED | |
| goal_text | VARCHAR(500) | 目标文本快照 |
