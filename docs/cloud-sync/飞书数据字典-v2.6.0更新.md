## 新增表

| 表 | 用途 |
|---|---|
| `behavior_module` | 九大行为模块 |
| `behavior_catalog_metadata` | 主行为模块、顺序、是否有子行为 |
| `behavior_group` | 前端推荐分组 |
| `behavior_group_item` | 分组与主行为关系及顺序 |
| `behavior_group_status_option` | 文件明确的分组状态栏选项 |
| `behavior_catalog_option` | 子行为和表现/状态选项，含父子关系和“其它”文本标志 |
| `behavior_environment_config` | 环境与主行为推荐关系 |
| `behavior_training_goal` | 主行为/子行为与标准训练目标关系 |
| `behavior_record_catalog_selection` | 详细记录实际选择的子行为和状态 |

## 关键约束

- 子行为编码为 `Bxxx_Syy`，表现/状态编码为 `Bxxx_Pyy`。
- `behavior_catalog_option.parent_option_code` 保存状态所属子行为。
- `behavior_record_catalog_selection` 使用 `(behavior_record_id, option_code)` 联合主键防重复。
- 所有主行为至少关联一个课程、一个环境和一个训练目标。
- 训练目标 11-165 不重不漏；父子选项与目标子行为关联均无孤儿数据。
- 完整字段、索引和外键见 `backend/docs/数据字典.md`；完整目录见 `backend/docs/behavior-catalog.json`。
