# 飞书前端接口文档 0.13.0 手动更新内容

## 版本和接口
- 契约版本：0.12.0 → 0.13.0，接口总数：28 → 33
- 新增：POST /auth/onboarding, GET/PUT/POST /me/students/*, PUT /me/profile
- 变更：PATCH /items 自动写change_log, GET /goals/{sn}/history, GET /goals/changes/recent
- period支持SEMESTER

## 认证模块
- POST /auth/wechat/login: {code, bindingCode?} → {accessToken, tokenType, expiresAt, newlyBound, profile}
- POST /auth/onboarding: 一步创建教师+学生+微信绑定+种子
- Header优先级: Authorization:Bearer > X-Teacher-Id
- 角色: 前端中文→后端role(ENUM)+position(中文原名)

## 学生管理
- StudentDetail新增: socialAdaptation/selfManagement/cognitiveLevel/languageComprehension/expressionAbility/hobbies
- 能力等级: 较弱/一般/良好
- 障碍类型: 英文码存,前端中文映射
- PUT /me/profile: {name,school,role,position}

## 训练目标变更日志
- PATCH自动写入training_goal_change_log
- GET /goals/{sn}/history: 单目标历史
- GET /goals/changes/recent?days=7: 近期聚合
- 字段: changedAt, fieldName, oldValue, newValue, goalText

## 学期报告
- SEMESTER: 2-6月春季,9-1月秋季,7-8月归春季
- AI报告SEMESTER样本上限200条
