## 版本和接口

- 契约版本：`0.11.0` → `0.12.0`。
- 接口总数：24 → 28。
- 新增：
  - `GET /student-evaluation/abc-distribution`
  - `GET /student-evaluation/behavior-description-trend`
  - `GET /training-plan/goals-progress`
  - `GET /training-plan/goals/{standardNumber}/records`
- `GET /student-evaluation/statistics` 增加三态、未分类、训练目标覆盖、7 天趋势、月度自然周、课程和环境统计。

## 详细记录契约

```json
{
  "functionCode": "OTHER",
  "functionOtherText": "获得活动机会",
  "statusCode": "INDEPENDENT",
  "assistances": [{ "code": "VERBAL_ASSISTANCE" }]
}
```

- `statusCode`：`INCOMPLETE`、`ASSISTED`、`INDEPENDENT`，统一大写。
- 快速记录状态初始为 `null`；保存详细记录时显式状态优先，未传状态但勾选辅助方式时自动判为 `ASSISTED`。
- 行为功能：`ATTENTION`、`ESCAPE`、`SENSORY`、`TANGIBLE`、`OTHER`。
- 选择 `OTHER` 必须填写 `functionOtherText`；其他功能禁止填写该字段。

## 学生评估联调

- 周统计 `dailyTrends` 固定周一至周日 7 项，无记录为 0。
- 月统计 `weeklyBreakdown` 按自然周动态 4–6 段，尚未到来的周不返回。
- `unclassifiedCount` 是未选择三态的快速记录，不进入独立率分母。
- `overview.trainingGoalCount` 统计已发生记录关联的全部标准目标去重数，不限是否激活。
- ABC 分布固定返回 5 项，无记录项为 0。
- 行为表现趋势只统计已保存详情且 B 字段非空的记录，按 trim 后完全一致文本分组。

## 训练计划联调

- 目标进度返回当前学生全部已激活目标，无记录目标次数为 0；自定义目标当前因无标准行为映射而为 0。
- 每条行为记录计入其主行为关联的全部标准目标，不按子行为过滤。
- 目标记录接口的 `subBehaviors` 和 `performanceOptions` 均为数组；`performanceText` 无选项时为“未填写”。
- 不存在的 `standardNumber` 返回 HTTP 404；`limit` 默认 10、最大 50。

完整字段以 `backend/docs/openapi.yaml` 0.12.0 和 `backend/docs/前端接口文档.md` 为准。
