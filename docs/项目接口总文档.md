本文档是项目级接口总入口，用于团队共同维护接口约定。当前已写入成员 B 本机后端已创建的 V2 接口；其他同学新增接口时，应继续写入本文档，而不是另起一套格式。

## 1. 文档定位

| 项目 | 内容 |
|---|---|
| 文档用途 | 项目总接口文档、前后端联调依据、Apifox 分组参考 |
| 当前版本 | `0.6.0` |

本文档负责记录“项目里有哪些接口、接口如何调用、谁负责、当前状态是什么”。如果某个模块需要非常详细的字段说明，也可以在本文档登记后，再链接到各自模块的详细文档。

## 2. 共同维护规则

新增、修改或删除接口时，负责同学需要同步维护以下内容：

1. 在“模块登记”中写清所属模块、负责人、状态和详细文档位置。
2. 在“接口总览”中新增或修改接口行。
3. 在对应模块的“接口详情”中补齐请求头、路径参数、Query、请求体、响应数据和说明。
4. 如果新增字段、枚举、错误码或数据结构，需要同步更新“公共约定”或“数据结构”。
5. 在“变更记录”中记录日期、修改人和修改内容。

接口状态统一使用：

| 状态 | 含义 |
|---|---|
| `待设计` | 需求存在，但接口路径、字段、返回值尚未确定 |
| `已确认` | 前后端已确认契约，但代码未完成或未验证 |
| `已实现` | 后端代码已实现，基本验证通过 |
| `联调中` | 已交给前端或其他成员联调 |
| `已废弃` | 不再使用，仅为兼容或历史记录保留 |

接口编号建议使用“模块前缀 + 序号”：

| 模块 | 前缀示例 |
|---|---|
| 系统 | `SYS` |
| 我的 | `MINE` |

## 3. 全局接口约定

### 3.1 基础地址

| 环境 | BASE_URL | 说明 |
|---|---|---|
| 本地开发 | `http://localhost:3000/api` | 前后端在同一台电脑时使用 |
| 局域网联调 | `http://<后端电脑局域网IP>:3000/api` | 前端同学在同一局域网访问时使用 |
| 真机/远程联调 | `https://<cpolar或ngrok地址>` | 需要 HTTPS，地址待生成后填入 |

本文档中的路径均为相对 `BASE_URL` 的路径。例如 `GET /health` 的完整本地地址为 `GET http://localhost:3000/api/health`。

### 3.2 请求头

| 请求头 | 必填 | 当前约定 | 说明 |
|---|---|---|---|
| `Content-Type` | 有请求体时必填 | `application/json` | JSON 请求体 |
| `X-Teacher-Id` | 业务接口必填 | `t001/t002/t003` | 白名单伪登录教师身份 |
| `X-User-Id` | 不支持 | - | 旧临时身份请求头已停用 |

`GET /health` 不需要身份请求头。

### 3.3 统一响应包体

所有接口统一返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

前端处理规则：

| 条件 | 前端处理 |
|---|---|
| `code === 0` | 读取 `data` |
| `code !== 0` | 展示 `message` |

错误响应示例：

```json
{
  "code": 40001,
  "message": "请求参数不合法",
  "data": null
}
```

### 3.4 通用错误码

| code | 含义 |
|---:|---|
| `40001` | 请求参数不合法 |
| `40002` | 当前用户尚未选择当前学生 |
| `40101` | 缺少或无法识别白名单教师身份 |
| `40401` | 资源不存在，或资源不属于当前用户/当前学生 |
| `40901` | 资源状态冲突，例如重复分配训练目标 |
| `40902` | 删除前需要二次确认 |
| `50000` | 服务内部错误 |

### 3.5 日期与时间

| 类型 | 格式 | 示例 |
|---|---|---|
| 日期 | `YYYY-MM-DD` | `2026-07-17` |
| 时间 | 带偏移的 ISO 8601 | `2026-07-17T09:12:45+08:00` |

后端统一按上海时区处理行为发生时间。

```json
  "assistanceResultText": "一次语言提示后返回座位。"

```

说明：A、B、C 均为自由文本；`assistances` 必传，可为空数组；只要保存过一次，`detailSaved` 永久为 `true`。
