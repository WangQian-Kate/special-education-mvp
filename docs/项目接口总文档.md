## 2. 共同维护规则

新增、修改或删除接口时，负责同学需要同步维护以下内容：

1. 在“模块登记”中写清所属模块、负责人、状态和详细文档位置。
2. 在“接口总览”中新增或修改接口行。
3. 在对应模块的“接口详情”中补齐请求头、路径参数、Query、请求体、响应数据和说明。
4. 如果新增字段、枚举、错误码或数据结构，需要同步更新“公共约定”或“数据结构”。
5. 在“变更记录”中记录日期、修改人和修改内容。

接口状态统一使用：

| 状态 | 含义 |
|---|---|
| `待设计` | 需求存在，但接口路径、字段、返回值尚未确定 |
| `已确认` | 前后端已确认契约，但代码未完成或未验证 |
| `已实现` | 后端代码已实现，基本验证通过 |
| `联调中` | 已交给前端或其他成员联调 |
| `已废弃` | 不再使用，仅为兼容或历史记录保留 |

## 3. 全局接口约定

### 3.1 基础地址

| 环境 | BASE_URL | 说明 |
|---|---|---|
| 本地开发 | `http://localhost:3000/api` | 前后端在同一台电脑时使用 |
| 局域网联调 | `http://<后端电脑局域网IP>:3000/api` | 前端同学在同一局域网访问时使用 |
| 真机/远程联调 | `https://<cpolar或ngrok地址>/api` | 需要 HTTPS，由 `scripts/tunnel/start-cpolar-tunnel.cmd` 生成并验证 |

本文档中的路径均为相对 `BASE_URL` 的路径。例如 `GET /health` 的完整本地地址为 `GET http://localhost:3000/api/health`。

### 3.2 请求头

| 请求头 | 必填 | 当前约定 | 说明 |
|---|---|---|---|
| `Content-Type` | 有请求体时必填 | `application/json` | JSON 请求体 |
| `Authorization` | 正式业务接口必填 | `Bearer <accessToken>` | 微信登录签发的会话令牌 |
| `X-Teacher-Id` | 仅 dev/test | `t001/t002/t003` | 本地回归兼容，生产环境禁用 |
| `X-User-Id` | 不支持 | - | 旧临时身份请求头已停用 |

`GET /health` 和 `POST /auth/wechat/login` 不需要身份请求头。

### 3.3 统一响应包体

所有接口统一返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

前端处理规则：

| 条件 | 前端处理 |
|---|---|
| `code === 0` | 读取 `data` |
| `code !== 0` | 展示 `message` |

错误响应示例：

```json
{
  "code": 40001,
  "message": "请求参数不合法",
  "data": null
}
```

### 3.4 通用错误码

| code | 含义 |
|---:|---|
| `40001` | 请求参数不合法 |
| `40002` | 当前用户尚未选择当前学生 |
| `40010` | 微信临时 code 无效或已经使用 |
| `40011` | 一次性教师绑定码无效、已使用或已过期 |
| `40101` | 缺少或无法识别白名单教师身份 |
| `40102` | Bearer 会话缺失、无效、已注销或已过期 |
| `40301` | 当前微信尚未关联教师 |
| `40401` | 资源不存在，或资源不属于当前用户/当前学生 |
| `40901` | 资源状态冲突，例如重复分配训练目标 |
| `40902` | 删除前需要二次确认 |
| `40903` | 微信或教师身份绑定冲突 |
| `50000` | 服务内部错误 |
| `50201` | 微信 code2Session 服务暂时不可用 |
| `50301` | 后端未配置微信 AppID 或 AppSecret |

### 3.5 日期与时间

| 类型 | 格式 | 示例 |
|---|---|---|
| 日期 | `YYYY-MM-DD` | `2026-07-17` |
| 时间 | 带偏移的 ISO 8601 | `2026-07-17T09:12:45+08:00` |

后端统一按上海时区处理行为发生时间。

### 3.6 正式微信登录与开发兼容身份

正式流程由前端调用 `wx.login()` 获取一次性 code，再提交 `POST /auth/wechat/login`。后端调用微信 `code2Session` 获取 OpenID；首次登录用一次性绑定码关联既有教师，后续返回随机 Bearer token。业务接口根据 token 解析当前教师、绑定学生和当前学生。

| 开发兼容值 | 教师 | 学校 | 职位 | 可切换学生 | 默认当前学生 |
|---|---|---|---|---|---|
| `t001` | 张老师 | XX市特殊教育学校 | 特教教师 | `s001` 小明、`s002` 小华 | `s001` 小明 |
| `t002` | 王老师 | XX市特殊教育学校 | 康复师 | `s003` 小红、`s004` 小丽 | `s003` 小红 |
| `t003` | 李老师 | XX市随班就读试点小学 | 班主任 | `s005` 小刚、`s006` 小强 | `s005` 小刚 |

正式联调注意事项：

- 前端不要发送 AppSecret，也不要直接调用 `api.weixin.qq.com`。
- 正式请求统一发送 `Authorization: Bearer <accessToken>`。
- token 无效或过期返回 `40102`，前端清除登录状态并返回欢迎页。
- 当前学生由后端保存；前端切换学生时调用 `PUT /me/current-student`。
- `X-Teacher-Id` 仅在 dev/test 环境保留，生产环境明确禁用。

### 6.5 学生评估

#### EVAL-001 查询日/周/月概况和行为趋势

| 项目 | 内容 |
|---|---|
| 方法 | GET |
| 路径 | `/student-evaluation/statistics` |
| 请求头 | `Authorization: Bearer <accessToken>` |
| Query | `period`、`referenceDate`，均必填 |
| 响应 data | `StudentEvaluationStatistics` |

`period` 可选：`DAILY`、`WEEKLY`、`MONTHLY`。统计数据来源于当前学生的随班记录，并分别与前一天、上一自然周或上一自然月比较。

响应包含当前周期概况、行为次数、上一周期次数、变化百分比和趋势方向。`UP` 前端显示红色，`DOWN` 显示绿色，`STABLE` 显示灰色；上一周期为 0 且本周期大于 0 时，`changePercent` 为 `null`。

响应同时包含三态/未分类计数、周一至周日 7 天趋势、月度自然周拆分、课程和环境聚合。独立率只以三态已分类记录为分母。
