## 3. 辅助方式一致性（严重不一致）

| VISUAL_PROMPT（视觉提示） | PARTIAL_PHYSICAL（半身辅助） | **code 不一致** |
| PHYSICAL_ASSISTANCE（身体辅助） | POSTURAL（姿势辅助） | **code 不一致** |
| DEMONSTRATION（示范） | POSITIONAL（位置辅助） | **code 不一致** |
| REINFORCEMENT（强化） | ADD_EXTERNAL_ITEM（增加外在物品） | **code 不一致** |
| ENVIRONMENTAL_ADJUSTMENT（环境调整） | CHANGE_TARGET_SIZE（改变目标物大小） | **code 不一致** |
| — | DEMONSTRATION（示范辅助） | **前端新增** |
| — | VISUAL（视觉辅助） | **前端新增** |

**结论**：辅助方式前后端 **完全不一致**。code 命名、分类逻辑、数量均不同。

- 后端按"提示层级"分类：语言→动作→视觉→身体→示范→强化→环境
- 前端按"刺激内/刺激外"分类：刺激内（增加物品、改变大小）+ 刺激外（全身体、半身、姿势、位置、语言、示范、视觉）

**影响**：联调时行为记录中的辅助方式字段无法对齐，AI 模块接收到的辅助方式 code 含义不明确。**需紧急统一。**
