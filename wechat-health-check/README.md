# 微信小程序后端连接验收项目

本目录是独立的最小联调项目，用于验证微信开发者工具能否请求本机 Spring Boot 后端。它不会替代成员 A 的正式前端项目。

## 验收接口

- 本地请求：`GET http://localhost:3000/api/health`
- 真机请求：`GET https://<cpolar 地址>/api/health`
- 请求头：不需要 `X-Teacher-Id`
- 成功条件：HTTP 状态码为 `200`，响应 `code` 为 `0`，并且 `data.status` 为 `UP`

预期响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "UP"
  }
}
```

## 使用方式

1. 启动后端，确认监听 `localhost:3000`。
2. 在微信开发者工具中导入本目录。
3. 使用测试号运行项目。
4. 页面会自动发起健康检查，也可以点击“重新测试”。
5. 页面显示“连接成功”，控制台输出连接成功，网络面板显示 HTTP 200，即完成联合验收。

微信开发者工具默认会校验服务器域名。本地 HTTP 联调时，需要由开发者在项目的“本地设置”中自行开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。该选项只用于本地开发，不用于真机或生产环境。

## HTTPS 真机联调

1. 按照 [`../scripts/tunnel/README.md`](../scripts/tunnel/README.md) 配置并启动 cpolar。
2. 复制脚本输出的 `https://.../api` 地址。
3. 在页面的“后端 BASE_URL”输入框中粘贴该地址。
4. 点击“保存并测试”。地址会写入小程序本地存储，重新打开页面后仍会使用该地址。
5. 真机显示“连接成功”且网络面板返回 HTTP 200，即完成 HTTPS 联调。

点击“使用本地地址”可以清除已保存的隧道地址并恢复 `http://localhost:3000/api`。
