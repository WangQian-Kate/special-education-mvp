## 通用约定

- 健康检查完整地址为 `GET /api/health`，不要求身份请求头。
- 除健康检查外，所有业务接口只接受 `X-Teacher-Id: t001/t002/t003` 请求头。
- 当前学生由后端保存和校验，不再由每个业务请求重复发送 `studentId`。
- `t001`、`t002`、`t003` 分别映射张老师、王老师、李老师及各自绑定学生。
- 日期使用 `YYYY-MM-DD`。
- 时间使用带偏移的 ISO 8601 格式，后端统一转换为上海时区。
- 所有响应统一使用 `{ code, message, data }` 包体。
- `code === 0` 表示成功，此时业务数据位于 `data`；非 `0` 时前端展示 `message`。
- 错误码使用数字：`40001` 参数错误、`40002` 未选择学生、`40101` 未识别教师身份、`40401` 资源不存在、`40901` 资源冲突、`40902` 删除进度确认、`50000` 服务内部错误。
- 删除成功返回 HTTP 200，`data` 为 `null`。

## V2 主要规则

- 一条行为记录代表一次发生，统计使用记录条数，不再使用 `frequency`。
- 快速记录时间由后端生成，补记时间由前端提供且必须在当前时间之前。
- A、B、C 为自由文本。
- 行为卡片类型与 B 的具体行为描述分开。
- 辅助方式保存稳定 code，补充内容可不填写。
- 辅助结果为自由文本。
- 详细记录任意一项有值即可保存，全部为空时拒绝；首次保存成功后 `detailSaved` 永久为 `true`。
- 新增当前用户、绑定学生、当前学生选择、训练目标库和学生训练计划接口。
- 学生评估按自然日、周一至周日和自然月统计随班记录，并与上一对应周期比较行为趋势。
- 标准训练目标库包含 10 个标准分类、165 项目标，并返回稳定的 `standardNumber`。
