## 通用约定

- 除 `GET /health` 外，所有业务接口要求 `X-User-Id` 请求头。
- 当前学生由后端保存和校验，不再由每个业务请求重复发送 `studentId`。
- 登录接入后，`X-User-Id` 将由认证上下文替代。
- 日期使用 `YYYY-MM-DD`。
- 时间使用带偏移的 ISO 8601 格式，后端统一转换为上海时区。
- code 使用大写下划线形式。
- 成功响应直接返回资源，不增加通用 `data` 外层。
- 错误响应统一返回 `code` 和 `message`。

## V2 主要变化

- 一条行为记录代表一次发生，统计使用记录条数，不再使用 `frequency`。
- 快速记录时间由后端生成，补记时间由前端提供。
- A、B、C 改为自由文本。
- 行为卡片类型与 B 的具体行为描述分开。
- 辅助方式保存每项 code 和必填内容。
- 辅助结果改为自由文本。
- 首次保存详情后，`detailSaved` 永久为 `true`。
- 新增当前用户、当前学生、训练目标库和学生训练计划接口。
- 学生评估按自然日、周一至周日和自然月统计随班记录。
