# 特殊教育课堂行为记录系统接口文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 文档状态 | 任务 6 实施前草案 |
| 接口版本 | `0.1.0` |
| 本地服务地址 | `http://127.0.0.1:8080` |
| 数据格式 | `application/json` |
| 字段命名 | `lowerCamelCase` |
| OpenAPI 文件 | `backend/docs/openapi.yaml` |

本阶段没有登录和认证接口，不需要携带令牌。微信登录、AI 分析、PDF 导出和离线同步不在当前接口范围内。

本文档已经补充正式数据库必需的观察周期 `studentId`，并写入启动前建议的“其他说明自动清理、上海时区、统计百分比两位小数”规则。现有 `openapi.yaml` 尚未同步这些草案调整，待接口文档确认后在任务 6 中统一更新。

## 2. 通用约定

### 2.1 ID、日期和时间

- ID 为正整数，对应 Java `Long` 和 MySQL `BIGINT UNSIGNED`。
- 日期格式为 `YYYY-MM-DD`，例如 `2026-07-16`。
- 时间使用带时区偏移的 ISO 8601 格式，例如 `2026-07-16T09:23:00+08:00`。
- 后端按上海时区保存和返回时间。
- 字典 code 使用大写下划线格式，例如 `CLASSROOM`、`LEAVE_SEAT`。

### 2.2 成功响应

成功时直接返回资源对象或数组，不增加统一的 `data` 外层包装。

| 状态码 | 场景 |
|---|---|
| `200 OK` | 查询或更新成功 |
| `201 Created` | 创建成功 |
| `204 No Content` | 删除成功，不返回响应体 |

### 2.3 失败响应

所有失败响应统一使用：

```json
{
  "code": "VALIDATION_ERROR",
  "message": "请求参数不合法"
}
```

| HTTP 状态 | code | 场景 |
|---|---|---|
| `400` | `VALIDATION_ERROR` | 参数格式、范围、条件必填或字典 code 不合法 |
| `404` | `RESOURCE_NOT_FOUND` | 学生、教师、观察周期或行为记录不存在 |
| `500` | `INTERNAL_ERROR` | 未预期服务异常 |

错误响应不会返回 SQL、堆栈、本机路径、数据库账号或密码。

## 5. 观察周期接口

### 5.1 创建观察周期

```http
POST /observation-session
Content-Type: application/json
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `studentId` | Long | 是 | 当前被观察学生 ID |
| `creatorId` | Long | 是 | 当前记录教师 ID |
| `observationDate` | Date | 是 | 观察日期 |
| `courseCode` | String | 是 | 课程字典 code |
| `courseOtherDescription` | String | 条件必填 | `courseCode = OTHER` 时必填，最多 255 字符 |
| `environmentCode` | String | 是 | 环境字典 code |
| `environmentOtherDescription` | String | 条件必填 | `environmentCode = OTHER` 时必填，最多 255 字符 |
| `observationDurationMinutes` | Integer | 是 | 观察时长，范围为 1—1440 分钟 |
| `periodBehaviorRemark` | String | 否 | 本周期行为备注，最多 1000 字符 |

请求示例：

```json
{
  "studentId": 1,
  "creatorId": 1,
  "observationDate": "2026-07-16",
  "courseCode": "CHINESE",
  "environmentCode": "CLASSROOM",
  "observationDurationMinutes": 40,
  "periodBehaviorRemark": "下午注意力有所下降。"
}
```

成功响应：`201 Created`

```json
{
  "id": 1001,
  "studentId": 1,
  "creatorId": 1,
  "observationDate": "2026-07-16",
  "courseCode": "CHINESE",
  "courseLabel": "语文",
  "courseOtherDescription": null,
  "environmentCode": "CLASSROOM",
  "environmentLabel": "教室",
  "environmentOtherDescription": null,
  "observationDurationMinutes": 40,
  "periodBehaviorRemark": "下午注意力有所下降。"
}
```

业务校验：

- 学生和记录教师必须存在。
- 教师必须与学生存在有效绑定关系。
- 课程和环境必须是有效字典 code。
- `OTHER` 对应的补充说明为条件必填。

### 5.2 查询观察周期

```http
GET /observation-session/{sessionId}
```

| 路径参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sessionId` | Long | 是 | 观察周期 ID |

成功响应与创建观察周期的响应结构相同。不存在时返回 `404 RESOURCE_NOT_FOUND`。

### 5.3 更新观察周期

```http
PATCH /observation-session/{sessionId}
Content-Type: application/json
```

允许修改：

- `observationDate`
- `courseCode`
- `courseOtherDescription`
- `environmentCode`
- `environmentOtherDescription`
- `observationDurationMinutes`
- `periodBehaviorRemark`

`studentId` 和 `creatorId` 创建后不可修改。PATCH 请求至少需要出现一个可修改字段。

请求示例：

```json
{
  "observationDurationMinutes": 45,
  "periodBehaviorRemark": "语言提示后能够继续参与课堂。"
}
```

PATCH 规则：

- 未出现在请求中的字段保持原值。
- 可空字段显式传入 `null` 时清空。
- 课程或环境从 `OTHER` 改为普通 code 时，自动清空对应的补充说明。

成功响应：`200 OK`，返回更新后的完整观察周期对象。

## 6. 行为记录接口

### 6.1 新增行为记录

```http
POST /behavior
Content-Type: application/json
```

请求字段：

| 字段 | 类型 | 快速记录 | 详细记录 | 说明 |
|---|---|---|---|---|
| `observationSessionId` | Long | 必填 | 必填 | 所属观察周期 |
| `studentId` | Long | 必填 | 必填 | 当前学生 |
| `creatorId` | Long | 必填 | 必填 | 当前记录教师 |
| `recordTime` | OffsetDateTime | 可省略 | 可填写 | 省略时使用服务器当前时间 |
| `antecedentCode` | String | 可空 | 可填写 | A 前因 code |
| `behaviorCode` | String | 必填 | 必填 | B 行为 code |
| `consequenceCode` | String | 可空 | 可填写 | C 后果 code |
| `assistanceCodes` | String[] | 可空 | 可多选 | 辅助方式 code 数组，元素不可重复 |
| `assistanceResult` | Enum | 可空 | 可填写 | 辅助结果 |
| `assistanceOtherDescription` | String | 可空 | 条件必填 | 包含 `OTHER` 时必填，最多 255 字符 |
| `frequency` | Integer | 默认 1 | 可填写 | 必须大于 0 |
| `durationSeconds` | Integer | 可空 | 可填写 | 必须大于或等于 0 |
| `remark` | String | 可空 | 可填写 | 最多 500 字符 |

快速记录示例：

```json
{
  "observationSessionId": 1001,
  "studentId": 1,
  "creatorId": 1,
  "behaviorCode": "LEAVE_SEAT"
}
```

详细记录示例：

```json
{
  "observationSessionId": 1001,
  "studentId": 1,
  "creatorId": 1,
  "recordTime": "2026-07-16T09:23:00+08:00",
  "antecedentCode": "TEACHER_QUESTION",
  "behaviorCode": "LEAVE_SEAT",
  "consequenceCode": "VERBAL_PROMPT",
  "assistanceCodes": [
    "VERBAL_PROMPT",
    "GESTURE_PROMPT"
  ],
  "assistanceResult": "PARTIAL_SUCCESS",
  "frequency": 1,
  "durationSeconds": 120,
  "remark": "语言提示后回到座位。"
}
```

成功响应：`201 Created`

```json
{
  "id": 2001,
  "observationSession": {
    "id": 1001,
    "studentId": 1,
    "creatorId": 1,
    "observationDate": "2026-07-16",
    "courseCode": "CHINESE",
    "courseLabel": "语文",
    "courseOtherDescription": null,
    "environmentCode": "CLASSROOM",
    "environmentLabel": "教室",
    "environmentOtherDescription": null,
    "observationDurationMinutes": 40,
    "periodBehaviorRemark": null
  },
  "studentId": 1,
  "creatorId": 1,
  "recordTime": "2026-07-16T09:23:00+08:00",
  "antecedentCode": "TEACHER_QUESTION",
  "antecedentLabel": "教师提问",
  "behaviorCode": "LEAVE_SEAT",
  "behaviorLabel": "离开座位",
  "consequenceCode": "VERBAL_PROMPT",
  "consequenceLabel": "教师提醒",
  "assistanceMethods": [
    {
      "code": "GESTURE_PROMPT",
      "label": "手势提示"
    },
    {
      "code": "VERBAL_PROMPT",
      "label": "语言提示"
    }
  ],
  "assistanceResult": "PARTIAL_SUCCESS",
  "assistanceOtherDescription": null,
  "frequency": 1,
  "durationSeconds": 120,
  "remark": "语言提示后回到座位。"
}
```

业务校验：

- 观察周期、学生和记录教师必须存在。
- 观察周期必须属于请求中的学生。
- 教师必须与学生存在绑定关系。
- B 行为必填，A 和 C 允许为空。
- A/B/C 和辅助方式必须使用有效字典 code。
- 辅助方式包含 `OTHER` 时，其他辅助说明必填。

### 6.2 查询学生行为记录

```http
GET /behavior/{studentId}
```

可选查询参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `startDate` | Date | 开始日期，包含当天 |
| `endDate` | Date | 结束日期，包含当天 |
| `courseCode` | String | 按课程筛选 |
| `environmentCode` | String | 按环境筛选 |
| `observationSessionId` | Long | 按观察周期筛选 |

请求示例：

```http
GET /behavior/1?startDate=2026-07-14&endDate=2026-07-16&courseCode=CHINESE
```

查询规则：

- `startDate` 和 `endDate` 必须同时提供。
- 开始日期不能晚于结束日期。
- 记录按 `recordTime` 倒序排列，时间相同时按 ID 倒序排列。
- 学生存在但没有记录时返回空数组。

成功响应：`200 OK`，返回行为记录对象数组。

### 6.3 更新行为详细记录

```http
PATCH /behavior/records/{recordId}
Content-Type: application/json
```

允许修改：

- `recordTime`
- `antecedentCode`
- `behaviorCode`
- `consequenceCode`
- `assistanceCodes`
- `assistanceResult`
- `assistanceOtherDescription`
- `frequency`
- `durationSeconds`
- `remark`

`studentId`、`creatorId` 和 `observationSessionId` 创建后不可修改。

请求示例：

```json
{
  "antecedentCode": "TEACHER_QUESTION",
  "assistanceCodes": [
    "VERBAL_PROMPT",
    "VISUAL_PROMPT"
  ],
  "assistanceResult": "SUCCESS",
  "frequency": 2,
  "durationSeconds": 90,
  "remark": "视觉提示效果较好。"
}
```

PATCH 规则：

- 未出现的字段保持原值。
- 可空字段显式传入 `null` 时清空。
- `assistanceCodes` 传入空数组时清空全部辅助方式。
- 辅助方式移除 `OTHER` 时自动清空其他辅助说明。
- 请求至少需要出现一个可修改字段。

成功响应：`200 OK`，返回更新后的完整行为记录。

### 6.4 删除行为记录

```http
DELETE /behavior/records/{recordId}
```

成功响应：`204 No Content`。

删除行为记录时同时删除其辅助方式关联。记录不存在时返回 `404 RESOURCE_NOT_FOUND`。

## 7. 行为统计接口

### 7.1 查询学生行为统计

```http
GET /statistics/{studentId}
```

可选查询参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `startDate` | Date | 统计开始日期，包含当天 |
| `endDate` | Date | 统计结束日期，包含当天 |
| `courseCode` | String | 按课程筛选 |
| `environmentCode` | String | 按环境筛选 |

请求示例：

```http
GET /statistics/1?startDate=2026-07-10&endDate=2026-07-16
```

成功响应：`200 OK`

```json
{
  "studentId": 1,
  "startDate": "2026-07-10",
  "endDate": "2026-07-16",
  "totalFrequency": 8,
  "items": [
    {
      "behaviorCode": "ATTENTION_DROP",
      "behaviorLabel": "注意力下降",
      "frequency": 5,
      "percentage": 62.50
    },
    {
      "behaviorCode": "LEAVE_SEAT",
      "behaviorLabel": "离开座位",
      "frequency": 3,
      "percentage": 37.50
    }
  ],
  "trend": [
    {
      "date": "2026-07-15",
      "totalFrequency": 3
    },
    {
      "date": "2026-07-16",
      "totalFrequency": 5
    }
  ],
  "environmentDistribution": [
    {
      "environmentCode": "CLASSROOM",
      "environmentLabel": "教室",
      "frequency": 8,
      "percentage": 100.00
    }
  ]
}
```

统计规则：

- 所有统计均对 `behavior_record.frequency` 求和，不按记录条数计算。
- 行为统计按频次倒序，频次相同时按 `behaviorCode` 升序。
- 趋势按日期升序。
- 环境分布按频次倒序。
- 百分比按总频次计算，四舍五入保留两位小数。
- 没有记录时 `totalFrequency = 0`，三个数组均为空。
- 统计结果实时计算，不保存统计副本。

## 9. 前端联调要求

- 前端发送稳定 code，显示后端响应中的中文 label。
- 创建观察周期时必须发送当前 `studentId`。
- 快速记录成功后保存响应中的行为记录 ID。
- 编辑和删除使用 `/behavior/records/{recordId}`，不能使用数组位置代替记录 ID。
- 日、周、月切换由前端计算 `startDate` 和 `endDate`。
- 查询日期范围必须同时发送开始日期和结束日期。
- 当前没有分页，查询结果按约定排序后完整返回。
- 当前教师和当前学生属于前端状态；后端根据请求 ID 和绑定关系校验。
