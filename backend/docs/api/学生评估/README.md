# 学生评估页面 API

## 页面范围

当前只实现行为频次统计。AI 智能分析等待成员 C，学期报告等待固定日期，导出和分享等待后续页面设计。

统计对象始终是 `X-Teacher-Id` 对应教师的当前学生，数据来源为随班记录。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/student-evaluation/statistics` | 查询日报、周报或月报行为频次 |

## 周期规则

- `DAILY`：`referenceDate` 当天。
- `WEEKLY`：`referenceDate` 所在周的周一至周日。
- `MONTHLY`：`referenceDate` 所在自然月。
- 学期报告：固定日期待确认，当前不开放虚假接口。

## 统计规则

- 每条快速记录计 1 次。
- 每条补记计 1 次。
- 保存详细记录不增加次数。
- 删除行为记录后次数同步减少。
- 直接使用记录条数，不读取或返回旧 `frequency` 字段。
