# “我的”页面 API

## 页面范围

当前只实现个人中心首页所需的当前用户、绑定学生和当前学生选择。资料修改、学生管理、导出记录历史和退出登录等待后续页面设计；使用帮助为前端静态页面。

除特别说明外，请求均携带：

```http
X-Teacher-Id: t001
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/me` | 返回当前用户资料、当前学生和是否需要选择学生 |
| GET | `/me/students` | 返回当前用户已经绑定的学生列表 |
| PUT | `/me/current-student` | 切换并持久保存当前学生 |

## 关键规则

- 资源教师、影子老师和家长使用同一页面结构。
- 当前学生必须与当前用户绑定。
- 绑定多个学生且尚未选择时，`GET /me` 返回 `requiresStudentSelection = true`。
- 绑定一个学生且尚未选择时，后端可直接将该学生设为当前学生。
- 当前学生被随班记录、训练计划和学生评估共同使用。
